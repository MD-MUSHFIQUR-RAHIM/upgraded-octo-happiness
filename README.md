# SCIN — Sparse Causal Intervention Networks

Research prototype: causal representation learning via sparse mechanistic
graphs for distribution-robust AI. Contains the research plan (v2.0), a
differentiable-DAG structure-learning library, and the two gate experiments
(synthetic causal-graph recovery and OOD generalization under spurious shift),
both of which passed their go/no-go gates on CPU.

See `PLAN.md` for the full research plan and `results/RESULTS.md` for results.
